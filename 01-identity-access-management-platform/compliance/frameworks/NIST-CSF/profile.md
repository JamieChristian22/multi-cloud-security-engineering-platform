# NIST Cybersecurity Framework IAM Profile

| Function | Category | IAM Implementation |
|---|---|---|
| Govern | Policy | Multi-cloud IAM standards, ownership, exceptions, and quarterly control reviews |
| Identify | Asset Management | Inventory workforce users, groups, roles, service identities, keys, and federated applications |
| Protect | Identity Management and Access Control | MFA, SSO, least privilege, conditional access, privileged role activation |
| Detect | Continuous Monitoring | Sign-in monitoring, anomalous activity findings, permission drift detection |
| Respond | Incident Management | Credential compromise, excessive privilege, orphaned identity, and break-glass runbooks |
| Recover | Improvement | Post-incident access review, policy correction, evidence preservation, lessons learned |
