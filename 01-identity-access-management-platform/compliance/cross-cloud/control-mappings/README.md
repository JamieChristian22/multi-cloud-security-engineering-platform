# Cross-Cloud Control Mapping

`control-matrix.csv` is the authoritative control inventory for this project.

## Status Definitions

- **Compliant** — implementation and current evidence are present.
- **Partially Compliant** — implementation exists but evidence or scope is incomplete.
- **Noncompliant** — control is missing or ineffective.
- **Not Applicable** — formally approved exclusion with documented rationale.

## Evidence Rule

A control cannot be marked Compliant unless the evidence artifact identifies the provider, tenant or account scope, collection time, collector, and file hash.
