# AWS IAM Compliance Implementation

## Native Services

- AWS IAM and IAM Identity Center
- IAM Access Analyzer
- AWS CloudTrail
- AWS Config
- AWS Security Hub CSPM
- Amazon EventBridge and SNS for alerting

## Required Outcomes

- MFA for root and interactive administrative access
- Temporary credentials for workforce and workloads
- No unapproved wildcard administrative policies
- Traceable role ownership
- Centralized CloudTrail logging
- Automated findings and remediation tracking
