# Google Cloud IAM Compliance Implementation

## Native Services

- Cloud IAM
- Cloud Identity
- Organization Policy Service
- Security Command Center
- Cloud Audit Logs
- Policy Analyzer and IAM Recommender
- Workload Identity Federation

## Required Outcomes

- No routine use of primitive Owner or Editor roles
- MFA for privileged workforce identities
- Service accounts have owners and documented purposes
- Service account keys are minimized
- Organization-level policy changes are logged and reviewed
- Workloads use federation instead of exported static keys where possible
