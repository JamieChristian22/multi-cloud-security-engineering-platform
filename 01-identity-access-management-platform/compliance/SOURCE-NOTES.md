# Authoritative Design References

The implementation was designed using current official guidance from:

- AWS IAM security best practices, AWS Config, AWS Security Hub CSPM, and CloudTrail documentation
- Microsoft Entra Conditional Access, Defender for Cloud regulatory compliance, Azure Policy, and Log Analytics documentation
- Google Cloud Security Command Center, Cloud Audit Logs, Organization Policy, and IAM documentation
- NIST SP 800-53 Rev. 5 and the NIST Cybersecurity Framework

This project is framework-aligned portfolio work. It does not claim independent certification, formal attestation, or production audit status.
